Architecture Decision Records

Every accepted decision behind dagworker's design, in the order it was made. An ADR is immutable once accepted; a changed decision gets a new ADR that amends the old one.

  1. ADR-0001: Public status vocabulary is exactly four values
  2. ADR-0002: Internal scheduling Phase is not part of the public API
  3. ADR-0003: Ready-set maintenance by in-degree decrement (Kahn), never rescan
  4. ADR-0004: Cycle rejection via an incrementally maintained topological order
  5. ADR-0005: Predecessor satisfaction is tracked per-edge, not by a bare counter
  6. ADR-0006: Every node carries a monotonic lease epoch used as a fencing token
  7. ADR-0007: Claim atomicity: one write grants ownership and records the deadline
  8. ADR-0008: The storage backend owns the clock for every deadline comparison
  9. ADR-0009: Delivery guarantee is at-least-once delivery with at-most-once accepted effect
  10. ADR-0010: Lease extension is a separate operation from acknowledgement
  11. ADR-0011: A retry is a new attempt on the same node; epoch and attempt are one field
  12. ADR-0012: Retry backoff is full jitter
  13. ADR-0013: Cross-instance work distribution v1 is pull-based competition
  14. ADR-0014: The partition assignment function is a swappable interface from day one
  15. ADR-0015: Leader election is reserved for maintenance, never for dispatch
  16. ADR-0016: Storage port shape: a mandatory core plus optional capability facets
  17. ADR-0017: Memcached is rejected as a storage backend
  18. ADR-0018: Every backend must pass one shared conformance suite
  19. ADR-0019: Observation and work-claiming are two separate interfaces
  20. ADR-0020: A per-node monotonic sequence is the ordering and resume primitive
  21. ADR-0021: Recovery is state-plus-notification, not event sourcing
  22. ADR-0022: Subscriber backpressure never blocks the producer
  23. ADR-0023: Scopes are implicit, prefix-isolated, and edges never cross them
  24. ADR-0024: Scope completion is Seal plus a non-terminal counter
  25. ADR-0025: Node identity is caller-supplied and insertion is idempotent
  26. ADR-0026: Payloads are opaque bytes with a size cap
  27. ADR-0027: Public Go API shape: options, context, errors, and shutdown
  28. ADR-0028: In-memory backend internals: struct-of-arrays, dense handles, sharding
  29. ADR-0029: Minimum Go version is 1.25
  30. ADR-0030: Version 1 ships exactly five trigger rules
  31. ADR-0031: Repository and module topology is a multi-module monorepo
  32. ADR-0032: Priority is a first-class ready-set ordering key
  33. ADR-0033: The blocking Claim wakeup protocol
  34. ADR-0034: Configuration is per-scope with conservative library fallbacks
  35. ADR-0035: Worker trust model: cooperative workers and a plain integer fencing token
  36. ADR-0036: Node and edge removal semantics and the cascade policy
  37. ADR-0037: The gRPC, HTTP, and daemon network surface is in scope and optional
  38. ADR-0038: Storage mutation primitives are fenced and return newly-ready successors
  39. ADR-0039: Coding standards and the strict lint configuration
  40. ADR-0040: Testing strategy, coverage policy, and CI topology
  41. ADR-0041: Amendments discovered during implementation
  42. ADR-0042: Backend deviations discovered during implementation
